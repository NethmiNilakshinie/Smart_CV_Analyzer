Smart CV Analyzer
This project analyzes the content of a user's CV using AI to provide tailored feedback, skill assessments, and professional career guidance.

💡 Features
CV Upload: Easily upload and process PDF CV files.

AI-Powered Analysis: Uses Google Gemini AI technology to deeply analyze CV content.

Career Insights: Provides actionable advice and recommendations suitable for the current job market.

🛠 Technologies Used
Python

Streamlit: For the web-based user interface.

Google Gemini AI: For intelligent CV analysis.

PyPDF2: For PDF file parsing and text extraction.

Plotly: For data visualization.

🚀 How to Run
Clone this repository to your local machine.

Install the required dependencies using the requirements.txt file:

pip install -r requirements.txt
Set up your Google API Key securely (using Streamlit secrets or environment variables).

Run the application:

streamlit run app.py
